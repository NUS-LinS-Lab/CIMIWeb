# CIMI project website

Public project page: https://nus-lins-lab.github.io/CIMIWeb/

This repository contains the attributed CIMI website, maintained separately from the anonymous submission page.

## Preview

Run `python3 scripts/serve.py --port 8001`, then open http://127.0.0.1:8001.

## Deployment

GitHub Pages serves the root of the `main` branch. All assets use relative paths compatible with the `/CIMIWeb/` project URL.

The source includes the v33 video, task and observation clips, and SVG figures. `paper.pdf` is the public 15-page paper with supplementary material appended; `supplement.pdf` is the public 7-page standalone supplement. Both PDFs include the author names and affiliations. The videos retain their original supplied content.
